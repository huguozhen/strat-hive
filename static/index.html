券商账户状态

现金请填写与账本余额对应的券商现金余额，不是可用资金；未计算委托冻结资金。

券商持仓

无持仓时留空；填写六位证券代码，未收录于本地资料的代码仍可对账。

导入格式示例

UTF-8 JSON；cash 为现金余额，cost 为每股或每份成本价（可为负），quantity 为整数。可导入以下券商状态对象，也可导入 CLI 的完整参数对象。

{"cash":"1000.00","holdings":[{"code":"600000","quantity":100,"cost":"10.0000"}]}

证券资料

建账前先同步资料；离线时可从本地文件导入。

文件格式：JSON 对象，含 source 和 securities 数组；每项含六位字符串 code、name、type（stock 或 etf）。导入会替换目录，失败保留原资料。
