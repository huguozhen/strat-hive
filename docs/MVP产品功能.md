# 策略蜂巢（StratHive）MVP 产品功能

## 1. 目标与范围

MVP 是面向个人投资者的本地**策略运行账本**。用户通过配套 Agent Skills 完成人工策略的建账、启动、成交记录、查询、即时对账和结束。首期支持沪深主板股票与 ETF。

一个资产账户对应一个真实券商账户，可关联多次策略运行。每次运行直接绑定所选策略的一个具体版本及一个资产账户，拥有自己的期初投入、现金、持仓和成交记录。运行是资产归属和复盘单位。

## 2. 核心功能

### 2.1 策略与运行

- 创建、查询人工策略，编辑名称和描述。创建策略时生成初始版本 `v1`。
- 创建后续版本时，将策略当前名称和描述保存为快照，版本号按同一策略递增。策略资料可以继续编辑，已保存版本的内容固定并可查询。详细规则的结构和格式留待后续定义。
- 创建具名运行时选择策略和资产账户，可指定版本号，省略时使用创建当时的最新版。版本在创建运行时绑定，待启动、运行中、暂停和已结束的运行均可回查该版本。采用其他版本时创建新运行。
- 启动时从账户未分配现金划入期初分配现金。运行期间允许暂停、恢复及记录真实成交，资金分配集中在启动和结束两个边界。
- 查看运行状态、策略版本、期初分配现金、期初本金、当前现金、持仓数量与成本、费用和成交记录。承接持仓缺少估值时，期初本金及依赖它的指标显示为待估值。

### 2.2 资产账户与建账

- 创建和维护资产账户，录入券商佣金费率、建账截止时点和期初现金。已有持仓录入证券、数量、账本成本和持仓日期。
- 纯现金账户可独立建账。存在持仓时，引导用户先准备策略版本，再创建并启动承接运行，将持仓全部按数量分配。可为各承接运行同时分配现金。
- 维护账户最新现金、持仓、成本及佣金费率。外部入金和出金影响账户总现金与未分配现金。
- 账户查询展示总现金、未分配现金、持仓和相关运行。账户现金应等于未分配现金加各运行现金，账户持仓数量应等于各运行汇总。

### 2.3 交易日志

- 新增、查询、更正和删除已成交买卖，按运行、标的和时间筛选。支持输入证券代码或准确名称并校验。
- 交易按数量录入，成交金额由价格与数量计算。明细包含证券、方向、时间、价格、数量、佣金、印花税、过户费、理由和备注。
- 按账户佣金费率和内置的市场、品种、方向及成交日规则计算费用。允许逐项覆盖以匹配回单，并展示总费用。
- 支持在建账截止之后补记真实成交。暂停或已结束的运行可补记其运行期间的真实成交。影响退出结果的更正必须能重算并维持资产归属一致。

### 2.4 结束与持仓交接

- **卖出退出**。录入真实卖出，持仓归零后结束运行，剩余现金全部划回账户未分配现金。
- **承接退出**。将剩余持仓整体交给同一资产账户下一个待启动的新运行，作为新运行的期初持仓。交接、旧运行现金归还和新运行启动同时完成，新运行可从账户未分配现金分配期初现金。
- 结束成功后旧运行现金和持仓均为零。交接保留证券数量和历史账本成本，单独记录来源、去向、时间和估值。交接属于资产归属变更，实际买卖仍由成交日志记录。
- 同一交接估值用于旧运行的期末和新运行的期初。缺少可靠估值时可完成记账交接，相关绩效标记为待估值。

### 2.5 即时对账

- 手工输入或导入券商最新账面现金、持仓数量及可选成本。
- 对比券商与资产账户状态，校验账户现金与运行及未分配现金汇总、账户持仓与运行持仓汇总。
- 返回现金、数量及可比成本的差异。券商成本口径未知或不一致时标记不可比。盘中与盘后均按相同的账本字段核对。
- 对账结果即时返回，资产事实由独立的记账操作维护。

## 3. 交付与验收

Agent Skills 是 MVP 的产品入口，负责收集必要输入、确认关键操作并向用户解释结果。CLI 以结构化 JSON 向 Agent 提供结果，直接调用用于自动化测试和排障。

产品验收由用户通过 Agent Skills 完成，覆盖以下场景：

1. 纯现金建账，以及已有持仓按数量分配给一个或多个运行的建账。
2. 创建新版本并按指定版本或当时的最新版创建运行。验证编辑策略资料、创建新版本后，历史运行仍可查到原版本。
3. 运行启动、期初现金分配、买卖记录、费用覆盖、成交更正和状态查询。
4. 并行运行间的资产隔离、账户汇总、运行中的普通调资拒绝，以及即时对账差异。
5. 卖出后归还资金，以及在同账户交接给新运行后归零结束。验收交接前后账户持仓总量和账本成本连续。

## 4. 后续范围

下一期提供 Web UI 和本机 HTTP 入口，并扩展复盘、收益和市值仓位。TUI 按实际终端使用需求另行评估。实时行情、通用运行中调资、券商接口自动接入、回测、策略规则配置、复杂数据分析和历史交易批量导入留待后续评估。MVP 查询以当前资产状态和确定性账本指标为主，对账历史与账户历史快照随实际需求另行规划。

真实交易由用户在券商端执行。自动选股、策略模板市场、新闻事件理解和大模型策略生成均在首期范围之外。
