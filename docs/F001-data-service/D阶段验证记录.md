# 阶段 D 验证记录

日期：2026-11-24，环境 Linux x86_64，4 核、8,326,938,624 字节内存（约 8GB），无 swap。本次所有历史实测使用 `/tmp/strathive-cne-*` 独立目录，未配置用户真实历史库、修改投资账本或启用用户定时器。机器可用磁盘约 83GB。

## 安装与后端

- 固定源码：[CNEquity 0.25.0 / dd6881ad7a3e8fce4ed4314711c99f6251ec06f8](https://github.com/rootSunc/CNEquity/tree/dd6881ad7a3e8fce4ed4314711c99f6251ec06f8)。tag 的实际提交通过 Git 核验，运行进程同时核验 distribution 版本和安装源码提交。
- 独立解释器 CPython **3.14.10**；未修改系统 Python 或 Core 的依赖锁。完整依赖见 [实测元数据](D阶段实测.json) 和仓库 `scripts/history/{requirements.lock,build-requirements.lock}`。
- 实装主要依赖：DuckDB 2.0.0、Polars 1.42.1、PyArrow 25.0.0、NumPy 2.5.1、pandas 3.0.3、curl_cffi 0.15.0。`uv pip check` 检查 44 个包，兼容性通过。
- 独立环境按文件逻辑大小测得 **708,759,251 字节**（约 676MiB，含构建工具和运行期间生成的字节码）；DuckDB 两个扩展合计 **107,316,270 字节**（约 102MiB），不含原有 Python 基础运行时及 uv 下载／构建缓存。安装阶段部分 PyPI 请求超时，使用上游 frozen lock 导出带哈希依赖并经 curl 下载同版本、验证 SHA-256 后安装；没有放宽锁或降低 Python 版本。安装脚本本身没有在另一个全新联网环境完整重跑。
- `ducklake`、`sqlite_scanner` 首次安装并加载成功，随后 `doctor` 返回 `installed`，已验证缓存复用。
- 交易所目录源最初在 certifi 路径下遇到证书链验证失败；改用系统信任库的标准 SSL context，保持 TLS 验证，成功读取。实现没有关闭证书校验。

扩展窗口第一次运行已完成三年日线，分钟校验中发现逐行重建整天分钟集合造成不必要 CPU 开销。改为常数时间时段判断，并主动终止该测试进程，再用相同请求恢复：已提交日线仍可读取，running 分钟任务及未执行因子任务成功补齐。66.18 秒是**改进后续跑**的测量，不是全新三年首次回填总耗时；不能据此宣称全市场耗时。离线测试另覆盖初始化参考资料失败后的规划恢复。

全市场目录以 TDX 当前股票与交易所 ETF 目录取并集。实测发现 12 只交易所 ETF 不在 TDX 证券目录中，已加入请求清单，后续若源端不提供其行情则应报告缺口。本次没有据此宣称这 12 只已获得历史行情。已知 ETF 上市日用于排除上市日前无需覆盖的日期；未知股票上市日或停牌证据不会被猜测为完整。

本次没有全市场三年价格采集，也没有用证券目录读取替代该验收。大规模回填由显式 `data sync --period 1d` 执行；分钟清单默认仍为空。

## 数据占用及容量校准

按已提交快照的实际 Parquet 文件统计：

| 数据集 | 当前行数 | 活跃文件数 | 活跃 Parquet 字节 | 每行粗算 |
| --- | ---: | ---: | ---: | ---: |
| 日线 | 2,904 | 37 | 153,899 | 53.0 字节 |
| 1 分钟 | 57,600 | 60 | 1,040,624 | 18.1 字节 |
| 因子 | 2,904 | 37 | 65,478 | 22.5 字节 |

这批库中所有 Parquet（含旧修订）合计 2,938,226 字节。小证券池的压缩、分区和元数据比例不能直接代表全市场：日线落在原 30–100 字节模型内，分钟在本样本中压缩更高。环境实装低于原 2–5GB 预算，但应另计 Python 运行时、安装缓存、临时合并、导出、修订和备份。

继续保留最初 **20–30GB 工作磁盘**建议；不根据四证券样本承诺全市场总容量或时间。默认最多 100 个证券批量发布、2 个源请求并发、2 个查询线程、2GB DuckDB 连接预算。旧修订与已采集历史不自动删除，所以长期容量没有固定上限；低于 20GB 报警、低于 10GB 暂停新增历史写入。

## 查询、测试和发布边界

- 57,600 根 1 分钟线直接打印请求返回 `history_export_required`；JSONL 导出实得 **57,600 行**，manifest 行数一致且覆盖完整，未静默截断。JSONL 为 28,490,832 字节，说明文本导出远大于压缩后端。
- 四证券三年数据前复权后按季度聚合，返回 **52 根**；因子缺口为空。请求起始季度和当前未结束季度仍正确标为不完整，不把“有结果”视为整个自然周期完整。
- 历史未复权收盘读取成功；应用测试验证其不写入报价缓存，并维持现有自动边界估值与离线记账行为。
