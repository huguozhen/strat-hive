主方案已按 2026-11-19 访谈修订。目前已实现首期数据服务、当前估值及自动边界计量，验证进度见[执行记录](执行计划.md)；当前环境缺少银河 SDK 和账号配置，尚未实连行情源。源码支持、上游说明和实测结果在调研文档中分别标记；先按可替换来源开发，必要链路随实现验证，CNEquity 不作为首期盘中估值的前置依赖。

阶段 D 历史能力已实现并独立验证，使用方式和范围见 [D 阶段历史数据](D阶段历史数据.md)。现有盘中实连银河的待验收事项仍保留，不用历史样本替代该验收。
