# 持仓成本与运行估值

## 账本口径

StratHive 使用移动加权成本。买入费用计入持仓成本，卖出按数量比例结转，清仓后重新起算。账户级与运行级各自根据账本事实核算。对同一证券，账户单位成本和各运行单位成本分别由各自的成本总额和持仓数量计算，核对资产归属时使用数量汇总。

建账时，录入现有持仓数量、成本和持仓日期，并将数量全部归属到启动的运行。同账户交接时，证券数量和历史账本成本随持仓承接，账户级数量和成本保持连续。

交接估值用于绩效。旧运行以交接估值计算期末转出，新运行以同一值计算期初投入。账本成本与交接估值各自保留，缺少估值时可完成资产归属记录，相关绩效待估值。

## 券商口径资料

本次券商口径调研日期为 2026-11-07，重点是卖出、清仓及再次买入。系统对账优先核对现金和持仓数量，券商成本口径与系统一致时比较成本，其余情况标记为不可比。

- 同花顺**模拟炒股**的「盈亏成本」把累计买入支出、卖出回收和费用纳入计算。帮助说明全部卖出后，下一个交易日再买入时重新计算。真实交易端的成本来源和同日清仓后再买的逐笔口径仍待核实。 [同花顺模拟炒股帮助](https://moni.10jqka.com.cn/mcgiwt/other/mgbz)
- 东北证券区分持仓成本、摊薄成本和保本价。持仓成本随买入变化，摊薄成本随买卖变化，各口径对费用的处理也有差别。 [东北证券成本价说明](https://www.nesc.cn/main/a/20240306/71628.shtml)
- 东莞证券在 2017 年的说明中将同日卖完又买入视为连续操作。该说明适用于其当时的口径。 [东莞证券说明](https://edu.dgzq.com.cn/dgzq/views/main/a/20170525/5595.shtml)
- 长江证券列出多种成本价，并提示反复买卖同一股票可能影响计算结果。 [长江证券成本价说明](https://www.cjsc.com.cn/main/a/20250709/35761.shtml)

## 实盘核对

用券商正式说明或经用户确认的脱敏样本核对成本字段及设置、清仓后重买、费用覆盖和公司行为的影响。对缺少完整历史的期初持仓，保留输入成本和来源，并根据已知口径判断可比性。多个运行持有同一证券时，单独验证账户级成本、运行级成本以及交接后的成本连续性。
