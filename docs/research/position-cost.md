# 持仓成本口径调研

调研日期：2026-11-07。成本线以同花顺为参考，重点是卖出和清仓后再次买入的影响。本记录区分已核实事实、可供参考的其他券商口径和仍需验证的问题；后续不再调研银河证券口径。

## 结论

- 成本价存在多个口径；“买入均价”与会受卖出影响的“摊薄成本”不是同一指标，同一名称在不同券商的费用处理也不一定一致。[东北证券成本价类型说明](https://www.nesc.cn/main/a/20240306/71628.shtml)、[长江证券成本价类型说明](https://www.cjsc.com.cn/main/a/20250709/35761.shtml)
- 同花顺**模拟炒股**官方说明的“盈亏成本”综合买入支出和卖出回收：以累计支出减累计回收并计入手续费，再除以剩余股数；全部卖出后，下一个交易日再买入时重新计算。该来源只证明模拟产品的说明，不能直接证明用户的真实券商账户采用同一公式或同一周期规则。[同花顺模拟炒股帮助](https://moni.10jqka.com.cn/mcgiwt/other/mgbz)
- 当前未找到同花顺真实交易端对用户账户成本来源及口径的明确说明。不能把模拟炒股说明直接当成已验证的同花顺实盘口径。

## 可核实的一手资料

### 同花顺模拟炒股

[同花顺手机模拟炒股帮助](https://moni.10jqka.com.cn/mcgiwt/other/mgbz)区分买入成本和盈亏成本：前者反映买入成交和手续费，后者还考虑卖出回收。帮助明确说明股票全部卖出后，下一个交易日再次买入时重新计算相关成本。页面没有明确写出当日全部卖出又买入的逐笔公式，因此不能据此单独确认当日清零时如何续算。

### 其他券商的对照

[东北证券 2024 年说明](https://www.nesc.cn/main/a/20240306/71628.shtml)称其持仓成本随买入而非卖出实时变化，摊薄成本随买卖变化；其对保本价与摊薄成本的费用处理有不同说明。

[东莞证券 2017 年说明](https://edu.dgzq.com.cn/dgzq/views/main/a/20170525/5595.shtml)称同一股票当天全部卖出后又在当天买入，在该公司当时口径下仍按连续操作计算；全部卖出且当天不再买入才构成该说明中的清仓。此资料是其他券商的历史说明，不能外推为银河或同花顺当前实盘规则。

[长江证券 2025 年说明](https://www.cjsc.com.cn/main/a/20250709/35761.shtml)同样列出多种成本口径，并提示反复买卖同一股票时计算结果可能不准确。这进一步说明需要明确具体账户、口径和适用条件。

## 项目中仍需确定和验证

1. 同花顺真实交易端展示的成本字段名称、对应设置和实际口径，以及其显示的值是否来自券商柜台。
2. 当日清仓再买、清仓后下一交易日再买、跨非交易日、手续费和手动覆盖、分红及其他公司行为如何影响所选口径；使用券商正式说明或经用户确认的脱敏真实成交和持仓样本核对。
3. 用户以已有持仓建账时，通常只有券商当前成本和持仓数量，缺少成本周期内完整交易；这是否足以按所选口径继续计算，以及无法精确对齐时如何提示。
4. 同一证券拆分到多个逻辑资产池后，策略级成本与券商账户级成本如何分别计算及比较；不要假设各池成本简单相加即可得到券商展示的单位成本。

在口径确认前，可把上述成本作为待决的派生展示规则；不应把模拟炒股或其他券商的参考公式当成已经验证的同花顺实盘规则。
